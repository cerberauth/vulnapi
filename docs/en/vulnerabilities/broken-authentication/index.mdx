The scans in this group detect broken authentication issues.

- [Authentication Bypass](./authentication-bypass) — A vulnerability where an endpoint that requires authentication accepts requests with no credentials, allowing unauthenticated access.
- [API Authentication Brute Force Attack](./brute-force-attack) — A brute force attack, in the context of API authentication, is a trial-and-error method used by attackers to guess the correct credentials (username and password) or access tokens. Attackers use automated tools to make multiple requests to the authentication endpoint, trying different combinations of credentials until they find the correct one. This attack can lead to unauthorized access to the API and sensitive data.
- [JWT](./jwt) — JSON Web Token checks.
