:::caution
**Deprecated.** The `serve` command has been removed. The HTTP server was not properly designed and has been removed pending a redesign. Track progress and share feedback at [https://github.com/cerberauth/vulnapi/issues/303](https://github.com/cerberauth/vulnapi/issues/303).
:::

## Usage

```sh
vulnapi serve
```

Running this command prints a deprecation notice and exits; it no longer starts a server.
