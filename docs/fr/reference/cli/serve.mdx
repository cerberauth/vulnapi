**Obsolète.** La commande `serve` a été supprimée. Le serveur HTTP n'était pas correctement conçu et a été retiré en attendant une refonte. Suivez l'avancement et partagez vos retours sur [https://github.com/cerberauth/vulnapi/issues/303](https://github.com/cerberauth/vulnapi/issues/303).

## Usage

```sh
vulnapi serve
```

Cette commande affiche un avertissement d'obsolescence puis se termine ; elle ne démarre plus de serveur.
